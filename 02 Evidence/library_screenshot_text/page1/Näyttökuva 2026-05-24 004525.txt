2 How do! install modules/packages?

Installing additional modules and packages on your
server is a straightforward process.

Navigate to the Startup section of your server
management interface.

Locate the "Additional Node / Python Packages"
configuration field and enter the names of the
modules you wish to install.

Enter module names separated by spaces, for
example: "discord module2 module3"
