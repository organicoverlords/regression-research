## 2026-09-01 06:45 EEST architecture recovery
Recovered and re-proved the original stable routing contract from commits 4fc48a6 / 0591c2e / 41c8345. The intended public topology is ONE Tailscale Funnel handler at / targeting 127.0.0.1:3003. Public clone paths such as /clone-a/* and /clone-b/* must reach the 3003 front door with their prefixes intact; 3003 strips the clone prefix and dispatches to loopback clone backends. Separate Tailscale --set-path /clone-* handlers are incompatible with this design because Tailscale strips the prefix before forwarding, causing 3003 to misclassify clone traffic as root MCP traffic. This was reproduced directly: clone-b behind a separate /clone-b -> 3003 handler failed OAuth, while removing that handler and allowing root Funnel / -> 3003 to receive /clone-b/* intact passed four consecutive full authenticated smoke runs through 3003 -> 3042. 3042 uses the stable shared clone-b OAuth store and shared process receipt directory. Clone-a remains temporarily isolated on direct 3041 until its cutover is separately executed/verified. Do not create clone-specific Funnel handlers when using stable-front-door routing.
